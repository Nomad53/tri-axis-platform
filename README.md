# Tri Axis v0.1 — Industrial Prospect Intelligence

First working milestone for Tri Axis Supply Company.

## Current scope
- Dashboard
- Prospect discovery workspace
- Industry/city/relevance filtering
- Evidence-first prospect cards
- High/Medium/Low relevance model
- Duplicate protection utility
- Mock prospect API
- Responsive UI

## Deliberately not included yet
- Contact intelligence
- Email automation
- RFQ processing
- Quotations
- Orders / receivables
- Supplier management
- AI assistant

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Next build
